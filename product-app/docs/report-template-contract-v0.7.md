# 正式报告模板契约 v0.7

最后更新：2026-08-16

本文档继承 [v0.6 报告模板契约](./report-template-contract-v0.6.md) 的题目包、计分、阈值、诊断、建议和观察视角边界。v0.7 只升级新生成报告的总体画像表达和证据结构，不修改42道题、v1.1计分、45／55／70阈值、五类定位或建议触发逻辑。

## 1. 总体画像结构

新报告保存结构化 `profileNarrative`，同时保留 `overallProfile` 字符串数组以兼容旧读取方。`profileNarrative` 包含 `version`、`archetypeId`、`headline`、`paragraphs`、`evidenceIds` 和 `qualityFlags`。每段保存涉及的指标、维度、诊断 ID、题项模式 ID、片段 ID、回退 ID 与证据 ID。

总体画像固定按以下顺序生成3—4段：

1. 整体工作状态：说明有效维度整体状态、两轴相对关系和已实现 AI 影响的关系。
2. 已经形成的具体行为：只有维度达到70分才称为“较稳定优势”；低于70分最多称为“已有一定基础”或“仍在发展”。具体行为必须来自已选题项片段。
3. 主要断点：优先描述低分维度和已选发展片段。所有维度低于55分时，明确说明“尚未识别出稳定优势”，给出可起步的低风险真实任务。
4. 组织环境与责任边界：个人观察使用“看到、感受到、观察到”；组织群体和管理者视角继续使用各自既有证据边界。

## 2. 确定性规则

- 同输入、同版本得到字面一致的 `profileNarrative`、网页和 PDF。
- 候选行为只从 `ItemPatternRecord` 已选 `fragmentIds` 和 `AssembledDiagnosis` 已保存的诊断/回退片段中选择，不直接按单题最高或最低分补写行为。
- 维度分差不足或多个维度并列时，使用“整体较均衡/多个维度接近”等整体形态表述，不使用维度 ID 顺序制造高低。
- 全0（标准化0）不得出现“已形成”“相对扎实”“较稳定优势”；全25、全50可说明起步或已有一定基础，但不得称优势；全75、全100可称较稳定优势，但仍不能推断客观绩效。
- 已实现 AI 影响必须参与整体关系判断：能力高而影响低时说明实际影响尚未显现；影响高而能力低时说明影响集中在部分场景且方法仍需稳定；影响缺失时不做关系判断。
- “谨慎”等人格性描述不属于 v0.7 自动生成内容；行为句必须能回溯到题项片段和证据 ID。

## 3. 版本与历史

新报告使用 `expression_version=fixed_v0.7`、`profile_narrative_version=profile_narrative_v0.1`、`report_template_version=v0.7` 与签名制品 `rule-artifact-v0.7`。v0.6 及更早规则制品继续保留，旧 `report_snapshot` 不静默重算，历史内容哈希和重放使用其原快照与原制品。

## 4. Web/PDF 同源

网页和 PDF 均只读取同一 `report_snapshot.profileNarrative`；当旧快照没有该字段时回退到 `overallProfile`。证据 ID 进入快照哈希保护，但内部组装 ID 不在用户正文中展开。视觉层使用段落层级和责任边界提示，不改变整体编辑式、克制的报告风格。
