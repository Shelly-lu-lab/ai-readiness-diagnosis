# 正式报告模板契约 v0.4

最后更新：2026-08-13

本文档将已确认的 `04-个人与组织报告模板-v0.1.md` 转换为正式产品的可执行报告契约。它约束新生成的网页、PDF、员工组织摘要和报告快照；历史 v0.1—v0.3 报告保持不变。

v0.4 只升级报告表达和正式产品入口，不修改42道题、v1.1计分、45／55／70阈值、诊断类型或建议触发逻辑。管理者视角采用独立中文表达，不再从个人文案机械替换；用户可见正文不得出现“更值得先核对”“从你的观察看”或“还不是各处都能做到的日常做法”。

## 1. 统一原则

- 同一输入、同一规则版本必须生成字面一致的报告，不使用生成式 AI 临时改写。
- 所有整体描述必须由得分、轴间关系、维度排序和实际题项行为信号组装，不得只列举最高分和最低分。
- 维度解释优先回答“哪些具体行为相对稳定、哪些还未成为固定做法”，不以“表现不均衡”代替具体信息。
- 行动建议必须是使用者可以开始执行的动作；“检查、观察、衡量是否变化”只能放在成功信号，不能单独写成行动。
- 个人行动、组织行动和需要协同的行动在页面和 PDF 中必须分组展示。
- 前台将“系统计划”与“当前优先行动”合并为一个“下一步行动计划”章节；正文只呈现个人提升路径和组织改善路径，不重复列出一组“优先启动”卡片。底层继续保存完整路径和确定性建议项，供HR审核后转换为真实行动计划。
- 四象限结构上必须显示由45／55／70阈值形成的“涌现区（过渡区）”，不得让图形暗示只有四类诊断。

## 2. 报告类型和可见边界

| 报告类型 | 核心内容 | 行动范围 | 不得出现 |
|---|---|---|---|
| `personal_scoped` | 员工 AI 能力、A1—A4、AI 影响 | 个人可直接执行的提升行动 | B1—B4、组织事实推断、部门比较 |
| `immediate_personal` | 本人三项结果、八维、个人对组织的感受 | 个人提升为主，需要组织配合的内容单独标注 | 把本人感受写成组织客观事实 |
| `second_stage_personal` | 本人结果＋已发布的组织参照 | 个人提升计划＋组织已公布的改善方向 | 敏感部门点位、未审核组织结论 |
| `organization_scoped` | 组织准备度、B1—B4、样本和群体分布 | 组织改善行动 | A1—A4个人能力判断、个人明细 |
| `organization` | 组织三项结果、八维、部门保护后点位、群体分布 | 完整组织变革计划 | 把群体均值写成某个员工的能力 |
| `manager_self_assessment` | B1—B4管理者单人视角 | 优先核查和小范围试行的组织动作 | 群体共识、部门比较、员工分布 |
| `employee_organization_summary` | 已审核的组织主要发现和公开行动 | 组织向员工承诺的改善方向 | 部门点位、个人明细、未发布建议 |

## 3. 结果总览契约

每一项当前题目包内的结果必须同时展示：

1. 0—100分数。
2. 暂定表现等级。
3. 与该等级相对应的具体表现描述。
4. 解释边界。

三项结果的等级名称不得混用：

- 员工 AI 能力：起步／初步形成／发展中／较成熟。
- 组织 AI 准备度：支持不足／初步形成／发展中／较成熟。
- 已实现 AI 影响：影响有限／初步显现／较为明显／广泛显现。

总览结论必须先给出整体状态，再说明三项结果之间的关系，最后说明这些结果的证据边界。

## 4. 维度和整体画像契约

每个维度的可见正文按以下顺序组装：

1. 维度整体状态，使用本维度专属表达。
2. 0—2个相对稳定的题项行为。
3. 0—2个优先发展的题项行为。
4. 必要的数据状态和证据边界。

禁止将“这一维度表现不均衡”、“多个具体环节需加强”单独作为用户可见正文。如果没有达到题项信号门槛，应直接说明“四项回答较为接近，本次没有识别出明显单项差异”。

八维或四维整体画像不得只列举最高和最低分。它必须包含：

- 整体阶段。
- 个人能力与组织条件的关系（仅适用时）。
- 已经成形的具体行为。
- 当前的关键断点。
- 个人可控和需组织配合的部分。

## 5. 五类定位图契约

- 横轴为员工 AI 能力，纵轴为组织 AI 准备度。
- 前沿区、能力受阻区、组织待激活区和停滞区按当前分类规则绘制。
- 其余区域显式标记为“涌现区（过渡区）”。
- 图中绘制45、55、70阈值线或等价边界，不使用50／50中线暗示分类规则。
- 点位、区域名、坐标和文字结论必须同时展示。

## 6. 下一步行动计划契约

前台只展示一个章节，但依次包含：

1. **整体行动判断**：说明主要偏差、行动顺序和责任边界。
2. **个人提升路径**：只使用 A1—A4 和个人可控行动。
3. **组织改善路径**：只使用 B1—B4 和组织可控行动。
4. **行动路径**：按个人提升和组织改善分别呈现完整路径。每张路径卡包含当前阶段、具体做法和“做到什么算有进展”；确定性建议项只在底层保存，不在报告正文重复呈现。

行动卡的 `action` 必须以具体动作开始，例如“选定”、“写下”、“和经理一起”、“发布”、“完成三次试用”。`successSignal` 承担检查、比较和复测的职责。

## 7. 验收门槛

- 使用已确认模拟数据生成报告时，结果总览、整体画像、题项行为、五类定位和行动顺序必须与原模板语义一致。
- 个人报告不得输出组织专属行动；组织报告不得把责任交给某个员工。
- 报告不得出现“仍需结合题项分布”、“你较少报告”、“群体较普遍报告”等内部或不自然表达。
- 涌现区结果必须在图形和文字中同时可见。
- 底层建议的 `action` 不得只是“检查、观察、评估是否变化”；必须能说明开始做什么和留下什么产出。
- 网页和 PDF 必须来自同一个报告快照并通过视觉回归。
