# 正式报告模板契约 v0.5

最后更新：2026-08-15

本文档继承 [v0.4 报告模板契约](./report-template-contract-v0.4.md) 的结构、中文表达、题项行为解释、五类定位和行动计划规则，只增加公开个人42题观察报告。v0.5 不修改42道题、v1.1计分、45／55／70阈值、诊断类型或行动建议触发逻辑。

## 1. 新增报告类型

| 报告类型 | 题目范围 | 可见内容 | 固定边界 |
|---|---|---|---|
| `personal_observer` | 42题 I＋O＋V | 三项结果、八维画像、双轴五类定位、个人提升路径、可带回团队讨论的组织改善方向 | A类为本人行为自评；B类为本人对组织环境的观察；不是公司正式诊断，不代表员工共识 |

`personal_observer` 使用 `assessment_profile_id=personal_iov_observer_v0.1` 和 `questionnaire_package_id=combined_iov_v0.1`。它与企业 `combined_iov_v0.1` 共用题目集合，但证据基础、权限和后续流程不同。

## 2. 生成与权限规则

- 提交后由固定规则即时生成并自动发布，只进入本人“我的报告”。
- 不生成组织聚合、团队报告、部门比较、HR审核任务、员工组织摘要或二阶段个人报告。
- 组织指标统一称为“你感知的组织 AI 准备度”。
- 报告封面标题固定为“你的 AI 准备度与组织环境观察报告”。
- 组织行动分组固定称为“可以带回团队讨论的改进方向”，并提示需要与团队核实。
- 只有相同 assessment profile、题目版本、施测版本、计分版本和报告版本才可进行正式复测比较。

## 3. 冻结与历史兼容

- 新活动使用 `expression_version=fixed_v0.5`、`report_template_version=v0.5` 和签名规则制品 `rule-artifact-v0.5`。
- v0.2、v0.3、v0.4 报告继续按各自保留的签名规则制品验证和重放，不使用 v0.5 静默重写。
- 网页与PDF继续来自同一个不可变 `report_snapshot`。

## 4. 验收门槛

- 26题入口只生成 `personal_scoped`，不出现B类维度或双轴定位。
- 42题公开个人入口只生成 `personal_observer`，包含三项结果和八维，不创建任何组织报告。
- 用户可见正文不得把个人观察写成“公司已经”“员工普遍”或“组织已经确认”。
- 相同答案和版本必须生成字面一致的快照、网页和PDF。
