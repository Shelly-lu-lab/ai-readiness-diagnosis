## 尚不能宣称完成的生产门

| 门槛 | 完成证据要求 |
|---|---|
| PostgreSQL、Redis、对象存储 | `npm run test:dependencies`输出`PRODUCTION_DEPENDENCIES_OK` |
| 容器与HTTPS部署 | API `/ready`、Worker队列、Web反向代理和镜像构建全部在目标环境通过 |
| 真实飞书 | 企业免登、递归通讯录、卡片发放、提醒、报告通知及失败重试实测 |
| 备份恢复 | 在独立演练库恢复并完成行数、权限与报告哈希抽查 |
| 安全与隐私 | 公司信息安全审批、真实租户负向测试和日志脱敏检查 |
| 科学有效性 | 认知访谈、10—20人技术试点、50—150份Beta及后续结构/信效度分析 |
| 行业常模 | 多企业样本、测量等值与代表性评估后才允许发布百分位 |

## 当前结论

当前工程是可直接运行和进行合成数据/内部流程验收的正式产品代码，不是已完成生产上线和学术验证的成品。外部环境门全部取得实测证据前，目标仍保持未完成。
