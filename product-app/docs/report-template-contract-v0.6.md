# 正式报告模板契约 v0.6

最后更新：2026-08-15

本文档继承 [v0.5 报告模板契约](./report-template-contract-v0.5.md) 的完整结构、公开个人42题观察报告、题项行为解释、五类定位和行动计划规则，只修正组织相关维度的叙述视角。v0.6 不修改42道题、v1.1计分、45／55／70阈值、诊断 ID 或行动建议触发逻辑。

## 1. 组织维度叙述视角

- A类维度描述填写者本人的行为，可以使用“你会”“你已经形成”等个人行为表述。
- B类维度描述填写者对组织环境的观察，只能使用“你感受到”“你看到”“在你当前的工作环境中较常出现”等观察性表述。
- B类维度不得使用“你能够做到”“你已经能同时做到”“你推动了”“你建立了”等把组织机制归因于填写者个人能力或管理权限的表述。
- 指定管理者单人自评同样属于观察证据，应写成“从这位管理者的观察看”，不能直接写成已经确认的组织事实。
- 员工群体报告可以写成“员工的回答显示”或“较多员工观察到”；只有聚合证据满足样本规则时，才能描述组织层面的群体现象。

## 2. 报告类型与权限

v0.5 已确认的 `personal_scoped`、`personal_observer`、个人报告、组织报告、员工组织摘要和管理者单人自评边界保持不变。`personal_observer` 的B类结果仍不是公司正式诊断，不代表员工共识。

## 3. 冻结与历史兼容

- 新活动使用 `expression_version=fixed_v0.6`、`report_template_version=v0.6` 和签名规则制品 `rule-artifact-v0.6`。
- v0.2—v0.5 报告继续按各自保留的签名规则制品验证和重放，不使用 v0.6 静默重写。
- 网页与PDF继续来自同一个不可变 `report_snapshot`。

## 4. 验收门槛

- 个人观察报告的B类逐维解释不得出现“你已经能同时做到”“你能够做到”等个人能力归因。
- 多题同时较高或较低时，仍要列出具体组织行为，但连接句必须保持观察视角。
- 管理者单人自评不得冒充员工共识、群体统计或制度审计。
- 相同答案和版本必须生成字面一致的快照、网页和PDF。
