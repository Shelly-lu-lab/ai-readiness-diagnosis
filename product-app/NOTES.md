# 正式产品开发记录

最后更新：2026-08-17

## 已确认决策

- `product-app` 是正式产品工程；`prototype-*` 与 Alpha 沙盒只作历史样机。
- 42 道核心题、v1.1 计分和目前暂定阈值不在工程开发中静默修改。
- 报告由版本化固定规则生成，不依赖生成式 AI 临时改写。
- 管理者单人自评是单一视角证据，不得伪装成员工群体结论。
- 报告模板 v0.9.2 将总体评价固定为整合状态、工作链条、断点影响和下一步重点四段，并独立展示解释边界；个人观察报告没有组织行动时展示原因和继续观察信号。八维卡片继续回答整体含义、具体行为和影响或风险；行动章节为“优先判断摘要 → 3—5条当前优先行动 → 默认折叠完整发展地图”。
- 第一阶段正式入口采用邮箱验证码；公开个人用户先填写不计分工作背景，再独立选择是否授权去标识数据用于信效度和常模候选研究。拒绝授权不影响作答和报告。
- 邮箱账户与具体工作区已分离：个人、企业和平台入口保存登录意图；同一邮箱可拥有多个企业身份并在账户菜单切换。企业申请须由平台管理员审核，企业管理员默认进入活动工作台，不再默认进入“我的报告”。
- 个人研究同意采用追加式记录；企业研究授权由企业所有者单独确认。二者均不参与计分，也不影响正常测评和报告。企业首次发布活动前必须完成企业研究档案。
- “我的报告”已按全局邮箱账户聚合公开个人与各企业中的本人报告，并对详情和PDF继续执行逐租户、逐主体校验。

## 当前已验证

- TypeScript 全工程类型检查、单元／API 测试与生产构建通过。
- 自包含 Playwright 端到端流程通过：创建、发布、作答、提交、关闭、报告与行动转换。
- 行动计划支持更新0—100%进展及最新说明；首次产生进展时自动转为“进行中”，完成后锁定为100%并保留审计记录。
- 行动转换要求填写已确认资源、里程碑和复测日期，同时冻结来源报告、目标维度、证据引用和风险边界；未发布报告不能转为行动。
- 进展更新追加为 `action_check_ins`历史，里程碑可独立完成或重新打开。
- 活动发布通过 `questionnaire_releases` 冻结题目包、背景题、量表和规则哈希；公开问卷、草稿和提交都校验快照，不再从当前代码动态换题。
- 进行中的活动可以延期，但只能把截止时间向后调整；`campaign_schedule_amendments` 追加保存每一次变更，界面展示历史并把新的具体截止时间带入飞书提醒编辑。
- 未来开始时间的活动发布后进入 `scheduled`；问卷、范围和研究上下文在发布时即冻结，Worker 到点自动激活，员工提前打开链接会看到易懂的“尚未开放”提示。
- 员工完整作答后先进入提交确认层，只有再次确认才写入不可变答卷；按钮在提交期间锁定，避免重复操作。
- 生产 API 不再执行开发租户初始化，启动配置拒绝复用 Session 与 Worker 密钥；新租户的首个所有者还必须命中预先配置的飞书 Open ID 白名单。
- 邀请与提醒入口不再使用固定3天/7天默认期限；签名覆盖活动截止后的90天，服务端继续以最新活动窗口决定是否可作答。
- 重复或并发提交改为真正幂等：唯一约束仍负责防重，但 API 返回首次冻结的结果并重新签发报告取回凭证，不再让员工看到 `ALREADY_SUBMITTED` 冲突。
- 活动状态转换增加旧状态条件更新；HR手动关卷与Worker自动关卷竞态只产生一条转换审计和一份组织报告。
- 建议转行动增加“租户＋来源报告＋建议”唯一键；重复/并发转换返回同一行动项，只记录一次创建审计。
- 报告生成状态与发布状态分离；发布记录明确经过 `reviewed → published`，同时冻结审核主体、发布主体和两个时间点。即时及二阶段个人报告由 `system` 自动审核发布，组织报告保留HR人工审核发布。
- 报告发布使用已有唯一发布记录判断首次执行；重复发布不再重跑二阶段个人报告和员工摘要组装，也不重复记录审核或发布审计。
- 数据库升级到 `2026-08-18-v32`；v0.2—v0.9.1 规则制品继续以 retained 历史制品保留，新报告使用 `fixed_v0.9.2`、`item_pattern_v0.3`、`diagnosis_assembly_v0.2`、`profile_narrative_v0.4`、`action_selection_v0.3.1`、`development_pathway_v0.6`、`report_storyline_v0.2`、`pdf_layout_v0.4` 和报告模板 v0.9.2；问卷发布、分数与报告继续强引用确切规则制品和输入快照。
- 飞书 OAuth 登录已增加三重状态校验：签名与过期时间、发起登录的浏览器 `HttpOnly` Cookie、数据库一次性消费。生产 Session 使用 `__Host-` Cookie，Cookie 认证的写接口强制同源 `Origin`。
- 员工邀请凭证从 URL Query 迁移到 Fragment，员工端读取后立即清除地址栏并暂存在当前标签页；生产公开问卷接口要求当前飞书租户和 Open ID 与邀请一致，转发链接会被拒绝。
- 生产请求日志只保留 URL 路径，查询参数、Cookie 和 Authorization 不进入日志。
- 答卷去重、报告找回与草稿关联已从 `SESSION_SECRET` 分离至稳定 `DATA_LINK_SECRET`，邀请签名单独使用 `INVITE_SECRET`；生产配置拒绝四类密钥缺失、过短或复用。回归测试确认轮换 Session 密钥后仍能找回原报告且重复提交仍幂等。
- 新增内网 `/internal/metrics` Prometheus 指标与未处理错误 `errorId`；指标端点使用 Worker 凭证且不经 Web 反向代理对外暴露。Web 增加 HSTS、禁止嵌入与 `no-referrer` 策略。
- 内置规则制品由离线 Ed25519 密钥签名，运行环境只保存公钥；哈希、签名、保留状态、输入快照或报告快照任一被篡改都会阻断重放。数字签名只证明制品完整性，不代表信效度或干预效果已获验证。
- 历史重放改为验证原始冻结报告的规范化内容哈希，不再调用当前计分或报告模板重建旧报告。
- 匿名邀请不再在提交请求内同步标记完成；回执不保存`response_id`、提交时间、请求/Trace/Job ID，经15—45分钟随机延迟后按半小时批次、随机哈希顺序回写。重试不会创建第二份回执，Worker重跑不会重复处理。
- 就绪检查改为确认当前版本记录存在，避免历史版本在同一时间写入时产生非确定排序。
- 个人数据删除从“仅入队”补齐为可追踪闭环：实名员工和持报告凭证的匿名参与者均可发起，系统持久化排队、处理、完成与失败状态，Worker删除对象存储PDF及关联答卷/分数/报告。
- 删除完成结果新增分系统处理清单，分别确认PDF对象、数据库记录及不含答卷内容的保留审计，员工可查看实际删除数量和保留边界。
- 报告页增加授权清单，明确展示对象、查看/下载范围、到期时间与生效状态，撤销后再次访问立即被拒绝。
- 实名个人报告改用独立的活动级授权；团队报告授权接口明确拒绝个人报告，避免权限串用。员工提交前需确认版本化隐私说明，答卷冻结说明版本和同意时间。
- 企业补充题已实现发布快照、断点续答、提交校验和HR结果页；匿名活动禁止文字题并在关闭前隐藏结果，`n<5`自动抑制；实名文字原文查看记录高风险审计且不进入报告/PDF。
- PDF每页增加授权使用标识；下载审计只在PDF真实生成/读取成功后记为成功，失败则记录失败原因。
- 黄金回归已覆盖五类定位、阈值边界、16／26／42 题包、题项内部差异、组织配对样本和指定管理者边界。
- 已将主库中的个人32条、组织32条和6条背景情境建议编译为确定性规则；报告保存触发事实、题项片段、证据等级、行动族、排序分和抑制原因。
- 建议库增加启动时完整性门禁：固定检32+32+6数量、ID唯一、证据ID可解析、HTTPS链接、支持范围、证据边界、空内容和禁用表达；当前发布状态仍为`internal_pilot`，未冒充专家正式批准。
- 修复11条曾不可触发的个人／组织规则，并用合法分数与组织配对样本逐条证明64条主建议均可进入候选集；报告优先使用这些固定规则建议，不足3条时再用版本化发展路径确定性补足。
- 草稿编辑/删除已补齐；发布后的活动不可删除，必须通过取消、关闭和归档保留审计链。
- 飞书发放对象可在SaaS内从通讯录按部门选择；发布时冻结全员范围、实际人数和不可逆成员哈希，并拦截范围外邀请。
- 报告快照新增实际引用证据登记，包含来源链接、支持范围和“不能证明什么”的边界。
- 新 v0.9 报告将 `behaviorEvidence`、`storyline`、总体画像、`actionMode` 和 `selectionReason` 纳入内容哈希；选择顺序为安全／核查／治理前置、具体题项信号、低分维度、影响差距、背景障碍和地图回退。同一行动族去重、同维最多两条。

## 未完成与外部门槛

- 尚未由业务专家逐条审核64+6条建议的文字、触发条件和证据等级；规则编译完成不等于内容已经正式批准发布。
- 本机没有 Docker、PostgreSQL、Redis 和 MinIO 服务；生产依赖烟测脚本已完成，但尚未在本轮真实运行。
- 2026-08-10 实际执行 `npm run test:dependencies`，在启动前按预期被 `MISSING_DEPENDENCY_TEST_CONFIG:DATABASE_URL` 阻断；这不是代码测试通过，仍需提供真实依赖连接信息后重跑至 `PRODUCTION_DEPENDENCIES_OK`。
- 真实飞书免登、递归通讯录、消息卡片、失败重试和跨设备报告需企业应用凭证与回调域名。
- 信效度、测量等值性和行业常模只能在真实试点样本完成后验证。
